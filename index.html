webclaw 브라우저 손

Chrome 확장

이미 로그인한 내 Chrome 그대로, 웹사이트 일을 맡깁니다.

  • 로그인 세션 그대로페이지 읽기·클릭·양식 입력·파일 내려받기. 계정이나 쿠키를 따로 넘기지 않습니다.
  • 탭마다 채팅Chrome 사이드 패널에서 지금 탭에 대해 대화하며 일을 시킵니다.
  • 안전장치는 사람이 정합니다금지 사이트·승인 모드를 두고, 결제·삭제처럼 보이는 동작은 버튼으로 승인합니다. 비밀번호 같은 입력값은 기록에 남지 않습니다.
  • 여러 PC의 Chrome을 한 번에컴퓨터마다 설치된 확장이 버스에 붙어, 한 번의 지시로 동시에 움직입니다.

원격 MCP · Orca 모바일 연동

핸드폰에서 말하면,
내 PC가 즉시 움직입니다

원격 MCP(Server-Sent Events) 표준 지원으로, 스마트폰(Orca 모바일)에서 이동 중에도 집이나 사무실의 Windows/Mac PC를 자연어로 조절합니다.

  • 스마트폰에서 음성·자연어로 지시"내 PC에서 오늘의 미팅 요약 정리해줘", "현재 윈도우 화면 캡처 보여줘"를 핸드폰에서 그대로 말하세요.
  • 원격 MCP (SSE) 표준 내장포트 4001에 Server-Sent Events 기반 Remote MCP 서버가 탑재되어, 외부에서도 별도 중계 서버 없이 안전하게 연결됩니다.
  • 결과 알림 & 실시간 승인 루프webclaw의 결제·제출 동작이나 deskclaw의 주요 조작 시, 스마트폰 화면으로 즉시 승인 요청이 도착해 터치 한 번으로 안전하게 허가합니다.

Mac에 서버 앱 설치

앱을 내려받아 실행하세요. 메뉴 막대에 아이콘이 생기면 서버가 켜진 것입니다.

다른 컴퓨터 연결

Windows는 설치 프로그램, Linux·라즈베리파이는 한 줄 명령. 같은 사설망(Tailscale 또는 Headscale)이면 키 없이 자동 승인됩니다.

SSH와 무엇이 다른가요?

접속해서 시키는 대신,
나눠서 맡깁니다

SSH가 컴퓨터에 접속해 명령을 실행하는 방식이라면, 이 에이전트는 여러 컴퓨터에 작업을 나눠 맡기는 방식입니다.

  • 작업용 PC의 포트 개방 없이작업할 컴퓨터에 외부 접속용 포트를 열 필요가 없습니다.
  • OS가 달라도 같은 방식Windows·Linux·Mac에 같은 방식으로 지시하고 결과를 받습니다.
  • 여러 대가 동시에 작업한 번의 지시로 여러 컴퓨터가 작업을 나눠 처리합니다.

비밀키는 서버 머신 한 곳에만

다른 컴퓨터에는 마스터 비밀키를 복사하지 않습니다. 대신 컴퓨터마다 개인 출입증을 발급합니다.

  • 개인 출입증새 컴퓨터가 가입을 요청하면 그 컴퓨터 전용 토큰을 발급하고, 필요하면 하나씩 회수할 수 있습니다.
  • 사설망 자동 승인같은 사설망(Tailscale 또는 Headscale)이면 클릭 없이 승인되고, 밖에서 오면 운영자가 확인합니다. Tailscale Headscale
  • 지시는 한 곳에서만팀원 컴퓨터는 일을 받고 보고만 할 수 있습니다. 다른 컴퓨터에 지시할 수 없습니다.
