엔터프라이즈 & 라이선스

개인판은 무료(1인·서버 포함 2대), 3대 이상 대규모 병렬 제어·사내 폐쇄망 보안·조직 거버넌스는 엔터프라이즈에서 지원합니다.

1인 영구 무료

개인판 (Personal)

₩0 / 서버 포함 2대까지 영구 무료
  • 서버 컴퓨터 포함 최대 2대까지 동시 연결 (1+1 하드 인포스)
  • dureclaw + webclaw + deskclaw 통합 설치 패키지 제공
  • 원격 SSE MCP 브릿지 (Claude Code, Cursor, Windsurf 즉시 연동)
  • 📱 Orca 모바일 연동: 스마트폰으로 원격 PC 작업 승인 및 실시간 모니터링
  • Mac(Apple Silicon) · Windows(x64) 원클릭 인스톨러 지원
  • 기술 지원: GitHub 공개 이슈 게시판

엔터프라이즈 (Enterprise)

도입 문의 / 기기 규모 및 온프레미스 협의
  • 3대 이상 무제한 동시 병렬 — 대수 제한 없는 사내 전체 기기 풀 연동
  • 폐쇄망 전용 자립형 사설망(Headscale) 라이선스 및 온프레미스 제어 서버
  • 엔터프라이즈 작업 격리: workdir_only, shell: off(순수 AI 노드 모드)
  • 신원 보증 불변 감사 로그(Audit Trail) 및 사람 승인 결재 게이트
  • 버전 고정(DURECLAW_AUTO_UPDATE=0), 사내 배포 미러, SBOM 및 보안 감사 지원
  • 기업 전용 엔터프라이즈 빌드 제공 및 전담 엔지니어링 기술 지원 (SLA)

개인판 vs 엔터프라이즈 기능 비교표

엔터프라이즈 도입 시 제공되는 세부 기능과 현재 연구·개발 진행 중인 엔터프라이즈 로드맵 마일스톤 안내입니다.

제공 기능 및 명세 개인판 (무료) 엔터프라이즈 (Enterprise)
1. 네트워크 & 스케일
동시 연결 기기 대수 Mac, Windows, Linux, Edge 등 동시 연결 노드 수 최대 2대 (서버 1 + 워커 1) 제공 3대 이상 무제한 (계약 범위)
사설망(VPN) 환경 외부 SaaS 의존 없는 P2P 암호화 통신망 Tailscale SaaS 공용망 또는 로컬 LAN 제공 자체 온프레미스 Headscale 완전 독립망
네트워크 바인드 보안 공용 LAN(0.0.0.0) 노출 차단 제공 사설망 IP 및 127.0.0.1 한정 제공 전용 VLAN / Headscale 가상망 격리 바인딩
2. 보안 거버넌스 & 작업 격리 (Security & Isolation)
작업 디렉토리 강제 격리 (workdir_only) 상위 경로 탈출(../) 및 임의 경로 쓰기 차단 제공 기본 지원 제공 조직별 작업 루트 고정 및 엄격 검증
순수 AI 노드 모드 (shell: off) 쉘 실행을 원천 거부하고 AI 추론/분석만 수신 제공 노드별 정책 설정 제공 조직 정책 중앙 배포 및 강제 인포스
민감 시스템 자격증명 보호 .ssh, .aws, .env, 키체인 등 접근 사전 차단 제공 차단 패턴 매칭 제공 사내 보안 규정 맞춤형 차단 룰 추가
OS 커널 레벨 샌드박스 격리 macOS sandbox-exec, Linux Bubblewrap 적용 미지원 로드맵 (P2) OS 프로세스 물리 격리 컨테이너
가입 승인 게이트 & 1회용 등록 토큰 마스터키 노출 없는 기기별 1회용 가입(dcj1:) 제공 관리자 수동 승인 제공 1회용 만료 토큰 발급 및 기기 강제 퇴출
3. 감사 추적 & 데이터 자산화
소통 및 실행 로그 익스포트 누가/언제/어떤 명령을 내렸는지 확인 제공 Markdown / CSV 다운로드 (30일) 제공 보관 기간 무제한 및 전문 필터 검색
발신자 신원 불변 박제 (Tamper-Evident) 서버 인증 토큰 ID 및 사설망 IP 강제 바인딩 기본 로그 기록 제공 위조 방지 발신자 증적 바인딩
SIEM / 외부 감사 로그 전송 사내 보안 관제(Syslog, Splunk, Elastic) 연동 미지원 로드맵 (P2) 실시간 Syslog 및 웹훅 스트리밍
Git 저장소 자동 산출물 커밋/푸시 작업 결과 보고서를 사내 GitLab/GitHub에 자동 반영 노드 쉘 워크플로우로 수동 연동 로드맵 (P1) 백엔드 내장 자동 커밋 엔진
4. 산업용 OT 및 공급망 통제
버전 고정 & 자동 업데이트 끄기 DURECLAW_AUTO_UPDATE=0 으로 임의 패치 차단 제공 환경변수 제어 제공 사내 폐쇄망 전용 배포 미러 서버 지원
꺼진 기기 큐잉 (Store & Forward) 단선/재부팅 시 작업을 보관했다가 순차 전달 제공 지원 제공 대규모 기기 풀 일괄 배분(Batch) 지원
공장 설비(Modbus/PLC) 3단계 안전 인터록 하드웨어 E-Stop 준수, AI 제안 → 사람 승인 → 물리 출력 제어판 수동 승인 제공 OT 설비 안전 분리 아키텍처 컨설팅
전담 기술 지원 & SLA 도입 컨설팅, 온프레미스 인프라 연동 지원 및 전담 엔지니어 지원 커뮤니티 지원 (GitHub Issues) 제공 전담 엔지니어 기술 지원, 우선 대응 SLA, 사내 배포 기술 가이드
FAQ

자주 묻는 질문

“서버 포함 2대 무료”의 기준은 무엇인가요?
DureClaw 버스에 동시에 살아있는 컴퓨터(머신) 식별자 수입니다. 메인 서버를 구동하는 컴퓨터 1대와 작업용 컴퓨터 1대(합계 2대)까지 영구 무료로 제공됩니다. 같은 컴퓨터 안에서 브라우저(WebClaw)나 데스크톱(DeskClaw), 에이전트 데몬을 여러 개 띄우더라도 1대로 계산됩니다.
사내 업무용으로 혼자 쓸 때도 2대 안쪽이면 무료인가요?
네, 1인이 본인의 업무 생산성을 위해 2대 이하의 PC를 묶어 사용하는 것은 상업적 용도라도 완전 무료입니다. 3대 이상의 기기를 연결하거나 여러 사용자가 하나의 버스를 공유할 때 엔터프라이즈 플랜이 필요합니다.
로드맵에 표시된 기능은 언제 사용할 수 있나요?
로드맵(P1, P2) 기능은 엔터프라이즈 도입 협의 시 귀사의 요구 일정에 맞추어 우선적으로 개발 및 검증 빌드가 제공됩니다. 사내 보안 규정 검토가 필요하신 경우 별도 문의 부탁드립니다.
외부 인터넷 연결이 불가능한 완전 폐쇄망에서도 쓸 수 있나요?
네. DureClaw 엔터프라이즈는 자체 Headscale 망과 온프레미스 서버를 탑재하여, 외부 인터넷 연결이 완전히 차단된 사내 폐쇄망 환경에서도 100% 로컬 P2P 암호화 네트워크로 동작합니다.
