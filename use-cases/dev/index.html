Mac 한 대에서
모든 OS를 지휘합니다

Windows 빌드, Linux 서버, GPU 학습기를 각각 접속해 다루지 않아도 됩니다. Claude에게 말하면 맞는 컴퓨터가 동시에 일합니다.

개발자

이런 고민이 있다면

  • 빌드 환경마다 접속해야 한다Windows 빌드, Linux 배포, GPU 실험을 위해 창을 여러 개 띄워 SSH로 오갑니다.
  • 서버는 놀고 있다Claude Code는 Mac에서만 일하고, 성능 좋은 서버는 대부분 쉬고 있습니다.
  • OS마다 명령이 다르다셸·경로·인코딩 차이 때문에 스크립트를 OS별로 따로 관리합니다.
