# DureClaw Homepage

[dureclaw.baryon.ai](https://dureclaw.baryon.ai) 소스입니다. 정적 사이트(GitHub Pages)이며, 설치 원라이너가 받는 스크립트도 여기서 제공됩니다.

| URL | 내용 |
|-----|------|
| `/install` | 올인원 설치 (서버 + MCP + 사설망) |
| `/server` | 서버 설치 |
| `/agent`, `/agent.ps1`, `/agent.bat` | 에이전트 노드 설치 (Linux/macOS, Windows) |
| `/mcp` | Claude Code MCP 등록 ([DureClaw/dureclaw-mcp](https://github.com/DureClaw/dureclaw-mcp)) |
| `/mesh`, `/mesh-join.ps1` | 자체 사설망(Headscale) 도구 |

설치 파일(Windows 설치 프로그램, macOS 앱, 서버/에이전트 바이너리)은 이 저장소의 [Releases](https://github.com/DureClaw/homepage/releases)에서 받을 수 있습니다.

이슈·문의: [Issues](https://github.com/DureClaw/homepage/issues)
