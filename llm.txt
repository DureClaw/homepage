# DureClaw

> **DureClaw**는 분산 디바이스를 하나의 협력 AI 크루로 묶는 Local-First Agentic Bus 시스템입니다 (개인판 무료: 1인·서버 포함 2대). 마스터(Claude Code)가 중앙 두뇌로 추론하고, 각 노드(claw)는 물리 세계·브라우저·데스크톱의 손이 되어 안전하게 실행합니다. Keyless 엣지 + 결정 동결(Decision Freezing: LLM as compiler) 아키텍처로 API 키 노출 없이 초저지연(2µs)으로 재실행합니다.
> **DureClaw** is a Local-First Agentic Bus system that unites scattered computers into one collaborating AI crew (Free personal edition: 1 user, up to 2 machines). Claude Code acts as the central brain orchestrating execution, while native and open-source claw nodes act as physical, browser, and desktop hands. Features keyless edges and Decision Freezing (LLM as compiler) for sub-millisecond (2µs) replay without LLM API token costs.

- **Website**: https://dureclaw.baryon.ai/

## Core Capabilities & Benchmarks
- **One Brain, Many Hands**: Central inference on master (Claude Code via MCP), edge execution on distributed workers without local API keys.
- **Decision Freezing (LLM as Compiler)**: First run approved by human, subsequent runs compiled to deterministic rules — 0 LLM calls, 2µs execution (up to 143,136x acceleration measured on Raspberry Pi GPIO).
- **Private P2P Network (Headscale)**: Fully on-premise WireGuard mesh without third-party SaaS dependency. Air-gapped deployment ready.
- **Remote MCP SSE Bridge**: Built-in Server-Sent Events bridge exposing edge node tools to Anthropic Model Context Protocol clients.
- **3-Stage Industrial Safety Interlock**: [Level 1: AI proposal] → [Level 2: Orca mobile 2FA approval] → [Level 3: Edge HW watchdog / safety relay].
- **Tamper-Evident Audit Trail**: Single-use enrollment tokens (`dcj1:...`) with immutable cryptographic signatures.

## Native & Ecosystem Nodes
- [edgeclaw](https://dureclaw.baryon.ai/showcase/): Static Go single binary (No-CGo). Runs on any OS/CPU (Win, Mac, Linux, Pi Zero armv6, RISC-V). Direct GPIO, LED, buzzer, relay control.
- [webclaw](https://dureclaw.baryon.ai/showcase/): Chrome MV3 browser node. Lends authenticated real browser sessions to the fleet for search, scraping, and form automation.
- [deskclaw](https://dureclaw.baryon.ai/showcase/): Desktop GUI node (Win/macOS). Screen perception + mouse/keyboard RPA. Record once, replay deterministically without LLMs.
- [zeroclaw](https://github.com/DureClaw/zeroclaw): High-speed, memory-safe autonomous agent in Rust.
- [nullclaw](https://github.com/DureClaw/nullclaw): Micro-footprint agent in Zig with zero libc dependency.
- [picoclaw](https://github.com/DureClaw/picoclaw): Ultra-tiny Go agent deployable on minimal IoT boards.
- [nanobot](https://github.com/DureClaw/nanobot): Lightweight Python agent for workflow orchestration.
