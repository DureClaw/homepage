서버 앱 설치 webclaw 확장이 앱 안에 함께 들어 있습니다

팀을 지휘할 컴퓨터 한 대에 서버 앱을 설치하세요. 앱을 켜면 메뉴 막대·트레이에 아이콘이 생기고, 이 컴퓨터의 webclaw와 deskclaw를 메뉴에서 바로 연결할 수 있습니다.

macOS 서버 앱 Apple Silicon · M1~M4 · .dmg↓
Windows 서버 앱 Windows 10/11 · x64 · .exe↓
  1. dmg를 열고 DureClaw를 응용 프로그램 폴더로 끌어 놓습니다.
  2. 처음 실행할 때 “확인되지 않은 개발자” 경고가 뜨면 우클릭 → 열기를 누릅니다.
  3. 메뉴 막대에 DureClaw 아이콘이 생기면 서버가 켜진 것입니다. http://localhost:4000 제어판에서 연결 상태를 확인하세요.
  1. DureClaw-Server-Setup.exe를 실행합니다. 관리자 권한은 필요 없습니다.
  2. SmartScreen 경고가 뜨면 추가 정보 → 실행을 누릅니다.
  3. 작업 표시줄 트레이에 아이콘이 생기면 서버가 켜진 것입니다. http://localhost:4000 제어판에서 연결 상태를 확인하세요.
이미 서버가 있다면 — 작업용 PC에는 노드만 설치하면 됩니다. Windows 노드 설치 안내 →
2

Chrome에 webclaw 연결 이미 로그인된 브라우저를 그대로 씁니다

서버 앱 메뉴가 확장 폴더를 준비하고 Chrome 확장 페이지를 열어 줍니다. Chrome·Edge·Whale 등 Chromium 브라우저에서 똑같이 됩니다.

  1. 메뉴 막대의 DureClaw 아이콘 → 브라우저 손(webclaw) 연결…을 누릅니다.
  2. 열린 Chrome에서 chrome://extensions 로 이동해 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다 → 열린 폴더 ~/Library/Application Support/DureClaw/webclaw-extension 를 선택합니다.
  4. 툴바의 webclaw 아이콘을 고정하고, 아이콘을 눌러 사이드 패널을 엽니다.
  1. 작업 표시줄 트레이의 DureClaw 아이콘 → 브라우저 손(webclaw) 연결…을 누릅니다.
  2. 열린 Chrome에서 chrome://extensions (Edge는 edge://extensions)로 이동해 개발자 모드를 켭니다.
  3. 압축해제된 확장 프로그램을 로드합니다 → 열린 폴더 %LOCALAPPDATA%\DureClaw\webclaw-extension 를 선택합니다.
  4. 툴바의 webclaw 아이콘을 고정하고, 아이콘을 눌러 사이드 패널을 엽니다.
확인 — 서버 제어판 http://localhost:4000의 기기 목록에 webclaw@내PC가 보이면 연결된 것입니다. 사이드 패널에서 “연결됨” 상태도 확인할 수 있습니다.
앱 메뉴 없이 확장만 따로 설치하려면 (고급)

서버 앱이 준비한 폴더를 쓰는 대신, 확장 zip을 직접 받아 설정 파일을 채우는 방법입니다. 다른 PC의 서버에 붙일 때도 쓸 수 있습니다.

webclaw 확장 zip Chrome MV3 · 약 85KB · v0.11.4↓
  1. zip을 풀고 안쪽의 webclaw-extension 폴더를 확인합니다.
  2. config.local.json.example을 config.local.json으로 복사한 뒤 아래 값을 채웁니다.
  3. chrome://extensions → 개발자 모드 → 압축해제된 확장 프로그램을 로드 → webclaw-extension 폴더 선택.
{ "bus": "100.x.x.x:4000", "secret": "서버 비밀값", "workKey": "WK-...", "name": "webclaw@my-browser", "role": "executor", "caps": ["browser", "fetch", "dom", "agent", "webclaw"] }

서버 주소는 서버 앱의 노드 연결 주소 복사, 비밀값은 server.secret, Work Key는 제어판에서 확인합니다. 비밀값이 들어 있는 파일은 공유하지 마세요.

3

MCP 설치 모든 에이전트가 브라우저에 손을 뻗는 연결고리

MCP 서버가 에이전트와 DureClaw 버스를 이어 줍니다. 설치 스크립트가 Claude Code · Claude Desktop에 자동 등록하고, 다른 MCP 클라이언트용 JSON도 만들어 줍니다.

macOS MCP 설치 번들 Apple Silicon · 실행 파일 + 설치 마법사↓
Windows MCP 설치 번들 x64 · 실행 파일 + 설치 마법사 (Bun 불필요)↓

zip을 푼 뒤 터미널에서:

cd ~/Downloads/DureClaw-MCP-mac && chmod +x setup-mcp.sh && ./setup-mcp.sh

서버가 다른 컴퓨터에 있으면 주소를 지정합니다: ./setup-mcp.sh --phoenix ws://100.x.x.x:4000

zip을 푼 뒤 setup-mcp.bat을 더블클릭하세요. PowerShell을 쓰면:

powershell -ExecutionPolicy Bypass -File .\setup-mcp.ps1

서버 주소를 직접 지정하려면: setup-mcp.bat -PhoenixUrl ws://100.x.x.x:4000

서버 주소·비밀값은 자동 탐색됩니다. 같은 컴퓨터에서 서버 앱을 켜 두면 따로 입력할 것이 없습니다. 탐색에 실패하면 --phoenix/-PhoenixUrl과 --secret/-Secret으로 지정하세요.
Claude Code · Claude Desktop 말고 다른 에이전트에도 연결하기

설치 스크립트가 만든 mcp.json을 그 클라이언트의 MCP 설정에 붙여 넣으면 됩니다. Cursor·Codex CLI·OpenCode·Orca 모바일 등 MCP 표준을 지원하는 클라이언트는 모두 같은 방식입니다.

{ "mcpServers": { "dureclaw": { "command": "/Users/me/.dureclaw/mcp/dureclaw-mcpC:\Users\me\AppData\Local\DureClaw\mcp\dureclaw-mcp.exe", "args": [], "env": { "PHOENIX_URL": "ws://127.0.0.1:4000", "OAH_SECRET": "서버 비밀값" } } } }

정확한 경로와 비밀값이 채워진 파일은 설치 후 ~/.dureclaw/mcp/mcp.json (Windows: %LOCALAPPDATA%\DureClaw\mcp\mcp.json)에 있습니다.

확인 — 터미널에서 claude mcp list를 실행해 dureclaw가 보이는지 확인하세요. 에이전트를 재시작하면 MCP 도구가 로드됩니다.
4

첫 자동화 실행 말로 시키면 브라우저가 움직입니다

이제 에이전트에게 자연어로 브라우저 작업을 맡기세요. 에이전트는 get_presence로 연결된 webclaw를 찾고, send_task로 작업을 보냅니다.

“지금 열려 있는 탭 목록을 알려줘”탭 제목·URL·활성 상태를 읽습니다.
“로그인된 사이트에서 오늘 새 글 10개만 표로 정리해줘”세션 쿠키를 넘기지 않고, 그 브라우저 안에서 읽습니다.
“이 신청서를 채우고 제출 직전에 멈춰줘”입력은 자동, 제출은 사람이 승인합니다.
“탭 5개를 열어 각 페이지 가격만 뽑아 비교해줘”여러 탭·여러 사이트를 한 번에 처리합니다.

Claude Code에서 먼저 확인하려면:

mcp__oah__get_presence # webclaw@내PC 가 보이나요? mcp__oah__send_task(to: "webclaw@내PC", instructions: "[OPEN] https://example.com")
설치 완료 체크리스트 — ① 제어판에 webclaw 노드 ② claude mcp list에 dureclaw ③ get_presence에 webclaw ④ send_task 응답. 네 가지가 모두 되면 끝입니다.
막혔나요? 각 단계의 폴더 경로·명령은 운영체제를 바꾸면 함께 바뀝니다. 그래도 안 되면 이슈로 알려 주세요 ↗
왜 무제한인가

브라우저 안에서 실행하니까, 한도가 없습니다

클라우드 브라우저를 빌려 쓰는 방식이 아닙니다. 이미 켜져 있는 내 Chrome이 곧 실행 환경입니다.

01

실행 횟수·탭·사이트 제한 없음

MCP 도구 호출, 탭 수, 방문 사이트 수에 쿼터나 건당 과금이 없습니다. 업무량이 늘어도 비용이 늘지 않습니다.

02

모든 에이전트가 같은 손을 씁니다

Claude Code, Claude Desktop, Cursor, Codex, OpenCode, Orca 모바일… MCP 표준만 지원하면 어떤 에이전트든 webclaw에 작업을 보냅니다.

03

로그인 세션 그대로, CORS 없이

계정·쿠키를 밖으로 넘기지 않습니다. 브라우저 안에서 fetch·DOM·클릭·입력·다운로드를 실행하므로 사내 시스템도 그대로 다룹니다.

04

여러 PC의 Chrome을 동시에

각 컴퓨터의 webclaw가 버스에 붙습니다. 한 번의 지시로 여러 PC·여러 탭을 병렬로 움직입니다.

정확히 말하면 — 자동화 실행 자체에는 횟수 제한이 없습니다. 개인판은 서버 포함 2대까지 무료이고, 3대 이상 동시 병렬·조직 사용은 엔터프라이즈입니다. 대수 제한과 브라우저 자동화 횟수는 별개입니다. 플랜 비교 →

FAQ

설치 전에 많이 묻는 것

Chrome 웹스토어에서 설치할 수 없나요?

현재 webclaw는 서버 앱에 포함된 최신 확장을 압축해제된 확장 프로그램으로 로드합니다. 스토어 심사를 기다리지 않고 항상 최신 버전을 쓰기 위한 방식입니다. Chrome·Edge·Whale 등 Chromium 브라우저에서 동작합니다.

Windows에 Bun이나 Node를 따로 설치해야 하나요?

아니요. Windows MCP 설치 번들에는 dureclaw-mcp.exe 실행 파일이 들어 있어 Bun·Node 없이 바로 등록됩니다. macOS 번들도 실행 파일을 포함합니다.

Intel Mac도 되나요?

서버 앱은 Apple Silicon(M1~M4)용 dmg를 제공합니다. Intel Mac은 터미널 설치(bash <(curl -fsSL https://dureclaw.baryon.ai/install))와 MCP 한 줄 설치(bash <(curl -fsSL https://dureclaw.baryon.ai/mcp), Bun 필요)를 사용하세요.

MCP 없이 Claude Code 플러그인만 써도 되나요?

네. DureClaw Claude Code 플러그인만으로도 로컬 작업과 멀티머신 오케스트레이션을 쓸 수 있습니다. 다만 다른 에이전트(Cursor·Codex·Orca 모바일 등)까지 브라우저에 연결하려면 MCP 설치가 필요합니다.

여러 컴퓨터의 Chrome을 한 번에 움직일 수 있나요?

각 컴퓨터에 webclaw를 연결하면 webclaw@PC-A, webclaw@PC-B처럼 노드가 보입니다. 에이전트가 각 노드에 작업을 보내면 동시에 실행됩니다. 개인판은 서버 포함 2대까지 무료입니다.

비밀값·토큰은 어떻게 관리되나요?

서버가 발급한 비밀값은 서버 앱의 데이터 폴더에만 있고, MCP 설치 마법사가 자동으로 읽어 등록합니다. 화면에 출력하지 않으며, mcp.json에는 비밀값이 들어 있으니 공유하지 마세요.

브라우저 자동화, 이제 에이전트의 기본입니다

서버 앱을 설치하고 webclaw와 MCP를 연결하세요. 5분 뒤에는 쓰던 에이전트가 내 Chrome을 직접 움직입니다.
