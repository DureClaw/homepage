설치 전에 딱 세 가지

로그인은 어떻게 하나요?

macOS는 기존 Chrome과 분리된 전용 프로필로 시작합니다. 처음 한 번만 쓰는 사이트에 로그인하면 그 세션을 webclaw가 사용합니다. Windows는 첫 실행 때 기존 Chrome 프로필을 가져올 수 있고, Chrome 137+ App-Bound Encryption으로 로그인이 유지되지 않으면 한 번만 다시 로그인하면 됩니다.

이미 쓰는 Chrome을 그대로 쓰고 싶어요.

DureClaw Server 앱에 포함된 webclaw 확장을 Chrome·Edge·Whale에 직접 로드하는 방식도 그대로 지원합니다. 서버 앱 설치 가이드 →

서명 경고가 뜹니다.

현재 빌드는 서명 전입니다. macOS는 앱을 우클릭 → 열기, Windows는 SmartScreen에서 추가 정보 → 실행을 선택하세요.
