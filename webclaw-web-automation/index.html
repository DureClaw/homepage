  4. 툴바의 webclaw 아이콘을 고정하고, 아이콘을 눌러 사이드 패널을 엽니다.

왜 무제한인가

브라우저 안에서 실행하니까, 한도가 없습니다

클라우드 브라우저를 빌려 쓰는 방식이 아닙니다. 이미 켜져 있는 내 Chrome이 곧 실행 환경입니다.

01

실행 횟수·탭·사이트 제한 없음

MCP 도구 호출, 탭 수, 방문 사이트 수에 쿼터나 건당 과금이 없습니다. 업무량이 늘어도 비용이 늘지 않습니다.

02

모든 에이전트가 같은 손을 씁니다

Claude Code, Claude Desktop, Cursor, Codex, OpenCode, Orca 모바일… MCP 표준만 지원하면 어떤 에이전트든 webclaw에 작업을 보냅니다.

03

로그인 세션 그대로, CORS 없이

계정·쿠키를 밖으로 넘기지 않습니다. 브라우저 안에서 fetch·DOM·클릭·입력·다운로드를 실행하므로 사내 시스템도 그대로 다룹니다.

04

여러 PC의 Chrome을 동시에

각 컴퓨터의 webclaw가 버스에 붙습니다. 한 번의 지시로 여러 PC·여러 탭을 병렬로 움직입니다.

정확히 말하면 — 자동화 실행 자체에는 횟수 제한이 없습니다. 개인판은 서버 포함 2대까지 무료이고, 3대 이상 동시 병렬·조직 사용은 엔터프라이즈입니다. 대수 제한과 브라우저 자동화 횟수는 별개입니다. 플랜 비교 →

FAQ

설치 전에 많이 묻는 것

Chrome 웹스토어에서 설치할 수 없나요?

현재 webclaw는 서버 앱에 포함된 최신 확장을 압축해제된 확장 프로그램으로 로드합니다. 스토어 심사를 기다리지 않고 항상 최신 버전을 쓰기 위한 방식입니다. Chrome·Edge·Whale 등 Chromium 브라우저에서 동작합니다.

Windows에 Bun이나 Node를 따로 설치해야 하나요?

아니요. 서버 설치 프로그램에 dureclaw-mcp.exe가 포함되어 있어 Bun·Node 없이 바로 설치·등록됩니다. 별도 MCP zip은 설치 프로그램 없이 MCP만 업데이트할 때만 쓰는 고급 경로입니다.

Intel Mac도 되나요?

서버 앱은 Apple Silicon(M1~M4)용 dmg를 제공합니다. Intel Mac은 터미널 설치(bash <(curl -fsSL https://dureclaw.baryon.ai/install))와 MCP 한 줄 설치(bash <(curl -fsSL https://dureclaw.baryon.ai/mcp), Bun 필요)를 사용하세요.

MCP 없이 Claude Code 플러그인만 써도 되나요?

네. DureClaw Claude Code 플러그인만으로도 로컬 작업과 멀티머신 오케스트레이션을 쓸 수 있습니다. 다만 다른 에이전트(Cursor·Codex·Orca 모바일 등)까지 브라우저에 연결하려면 서버 설치 프로그램이 자동 등록하는 MCP가 필요합니다.

여러 컴퓨터의 Chrome을 한 번에 움직일 수 있나요?

각 컴퓨터에 webclaw를 연결하면 webclaw@PC-A, webclaw@PC-B처럼 노드가 보입니다. 에이전트가 각 노드에 작업을 보내면 동시에 실행됩니다. 개인판은 서버 포함 2대까지 무료입니다.

비밀값·토큰은 어떻게 관리되나요?

서버가 발급한 비밀값은 서버 앱의 데이터 폴더에만 있고, MCP 설치 마법사가 자동으로 읽어 등록합니다. 화면에 출력하지 않으며, mcp.json에는 비밀값이 들어 있으니 공유하지 마세요.

#증상원인이번 릴리스의 해결
1에이전트가 “webclaw MCP 도구가 없다”고 함MCP가 등록되지 않음설치 프로그램이 설치된 도구에 dureclaw로 자동 등록

3에이전트가 자기 설정 수정을 거부에이전트가 claude mcp add를 차단설치 프로그램이 대신 등록 (에이전트 아님)
4문서와 실제 도구 이름이 다름oah / dureclaw 혼용dureclaw 하나로 통일 · 문서는 mcp__dureclaw__*
5등록했는데 도구가 안 보임MCP는 세션 시작 시 로드완료 화면에서 “에이전트 도구를 새로 시작” 안내
6확장 설치가 여러 단계Web Store에 없음설치 프로그램이 폴더·설정 준비 + Chrome 확장 페이지 열기 (개발자 모드 → 폴더 선택)
7Service worker registration failed / relay.js 로드 실패패키징 목록에서 relay.js 누락stage 스크립트가 manifest·importScripts 참조를 검사하고, relay.js 포함 실패 시 릴리스 중단
8“버스 대기중”에서 멈춤config.local.json이 비어 있음설치 프로그램이 bus·secret·workKey·name을 자동으로 채움
