webclaw 개인정보처리방침

Chrome 확장 webclaw — DureClaw browser node가 접근하는 데이터와 처리 방식을 설명합니다.

시행일: 2026-11-10 · 문의: hello@baryon.ai

1. 한 줄 요약

webclaw는 사용자가 시킨 웹 작업을 사용자의 브라우저 안에서 수행합니다. 페이지 내용은 사용자의 로컬 DureClaw 서버(기본 127.0.0.1:4000)와 사용자가 선택한 AI 에이전트에게만 전달되며, Baryon Labs의 서버로 수집·전송되지 않습니다.

2. 접근하는 데이터

  • 페이지 내용 — 사용자가 지시한 탭의 DOM, 텍스트, 스크린샷. 작업 수행 중에만 읽습니다.
  • 탭 정보 — 제목·URL·탭 그룹. 작업 대상 탭을 찾고 작업 탭을 묶는 데 사용합니다.
  • 입력·클릭·다운로드 — 사용자가 요청한 폼 입력, 클릭, 파일 다운로드. 입력값은 로그에 남기지 않습니다.
  • 로컬 설정 — 서버 주소, Work Key, 서버 비밀값, 노드 이름. chrome.storage.local에만 저장됩니다.
  • 작업 기록 — 사이드 패널의 최근 작업·채팅 기록. 사용자가 지울 수 있습니다.

3. 데이터의 사용 목적

모두 사용자가 요청한 브라우저 자동화를 수행하기 위해서만 사용됩니다. 광고, 프로파일링, 데이터 판매, 신용평가에 사용하지 않습니다.

4. 데이터가 전송되는 곳

  • 로컬 DureClaw 서버 — 사용자의 컴퓨터 또는 사용자가 지정한 사설망(Tailscale/Headscale)의 서버.
  • 사용자가 선택한 AI 에이전트 — Claude Code, Claude Desktop, Cursor, Codex, OpenCode 등. 해당 도구의 데이터 처리는 그 도구의 정책을 따릅니다.
  • Baryon Labs 서버 — 전송하지 않습니다. 확장에는 자체 분석·광고 SDK가 없습니다.

5. 보관 및 삭제

설정과 작업 기록은 사용자의 Chrome 프로필에 보관됩니다. 확장을 제거하거나 chrome.storage.local을 지우면 삭제됩니다. 서버의 작업 기록은 서버 데이터 폴더에서 사용자가 직접 삭제할 수 있습니다.

6. 권한과 사용 이유

  • tabs, tabGroups — 작업 대상 탭을 찾고 탭 그룹으로 묶습니다.
  • scripting, <all_urls> — 사용자가 지정한 임의의 사이트에서 DOM 읽기·클릭·입력을 수행합니다.
  • debugger — 백그라운드 탭에서도 안정적으로 클릭·스크린샷을 수행하기 위한 Chrome DevTools Protocol 사용.
  • downloads — 사용자가 요청한 파일·스크린샷 저장.
  • sidePanel — 탭별 작업 채팅 UI.
  • storage — 로컬 설정·작업 기록 저장.
  • offscreen — MV3 서비스 워커에서도 DureClaw 버스 연결을 유지.

7. 보안

서버 비밀값은 chrome.storage.local에 저장되며 화면에 표시하지 않습니다. webclaw는 사용자가 설정한 금지 사이트·승인 모드를 따르며, 결제·삭제·전송처럼 되돌리기 어려운 동작은 사용자 승인을 요구할 수 있습니다.

8. 아동

이 확장은 만 14세 미만 아동을 대상으로 하지 않습니다.

9. 변경
