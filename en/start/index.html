Add an AI Teammate

Run the command below on a new machine and installation, configuration and connection are handled automatically. Replace SERVER_IP with your private network (Tailscale · Headscale) IP (100.x.x.x) or LAN IP (self-hosted private networks support JOIN=dcj1:...), or tell Claude "Add a worker" and it fills it in for you.

builder
Writes code
PHOENIX=ws://SERVER_IP:4000 ROLE=builder bash <(curl -fsSL https://dureclaw.baryon.ai/agent)
tester
Runs tests
PHOENIX=ws://SERVER_IP:4000 ROLE=tester bash <(curl -fsSL https://dureclaw.baryon.ai/agent)
analyst
Analyzes code
PHOENIX=ws://SERVER_IP:4000 ROLE=analyst bash <(curl -fsSL https://dureclaw.baryon.ai/agent)
executor
Runs commands
PHOENIX=ws://SERVER_IP:4000 ROLE=executor bash <(curl -fsSL https://dureclaw.baryon.ai/agent)
🪟 No commands needed on Windows — download and run the installer, then enter just the server address and role.
Bulk deploy to many PCs: DureClaw-Agent-Setup.exe /VERYSILENT /SERVER=ws://SERVER_IP:4000 /ROLE=builder
⬇ Download for Windows v0.5.5

If the Work Key is omitted, the server detects it automatically · if no agent name is given, it defaults to role@machine-name · on Windows, use the installer (tray) or the PowerShell script

fixer✓Patch complete
tester→Run tests + create PR
