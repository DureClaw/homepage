Distance-sensor traffic light — learn once, then the device decides instantly

SituationA Raspberry Pi Zero measures distance and lights a traffic light (red, yellow, green).
With DureClawThe master AI sets the thresholds (red under 12cm, yellow under 35cm) once, and the Pi freezes them as a local rule. From then on, decisions finish inside the device without calling the AI.
4.4–5.3 sasking the AI every time
36.7µsdevice decision after freezing
Up to 140,000×3 runs: 26,193–143,136×

Accuracy is the same — the rule the AI set is frozen as is, so the only thing that changes is decision latency.

Source — Edge brain traffic-light field report §5–6
