Adding AI to existing systems2

Example scenario
Mac (AI)webclaw browserdeskclaw desktop

Keep your web ERP as is, and add AI and automation

SituationLong-used web ERP and groupware systems have no API, or it is locked, so new automation or AI can’t connect and people copy data off the screen by hand.
With DureClawwebclaw reads ERP screens, clicks, fills in forms and downloads files in the already-logged-in browser. For installed clients, deskclaw operates the screen.
ConnectingAI on a GPU server analyzes data pulled from the ERP, then enters the results back into ERP forms or turns them into an Excel report on Windows. No need to replace the ERP or ask the vendor for an API.

There is no record yet of applying this directly to an ERP. Using the same method, we actually downloaded and organized 12 assignments from a logged-in university LMS (webclaw), and actually demonstrated recording and replaying a desktop program (deskclaw). Check your account and permission policies and the ERP’s terms of use before adopting.

Dedicated programs & licenses2

Real case
MacWindows (Office, Visual Studio)

Send the work to the PC that has the program

SituationSome programs are installed or registered only on specific PCs — Office, business sites that require certificates, development tools.
With DureClawWhen each node connects, it announces the programs installed on its PC as 'capabilities'. The master picks a PC with the needed capability and sends it the task; if the task gets stuck, it reassigns it to another node with the same capability.
In practiceA Windows node in production reports Word, Excel, PowerPoint, Outlook, Access and Visual Studio as capabilities.

Source — capability detection capabilities.ts · README — Why a team?

MacLicensed PCdeskclaw

Automate repetitive work while respecting license terms

ConceptThe software is not copied or moved to another PC. The licensed PC runs it as before; DureClaw only passes work and results back and forth.
HowIf there is a command line, use [SHELL]; if there is only a screen, deskclaw records and replays the clicks a person used to make. Usage records stay on that PC.

Note: whether unattended/automated execution or remote use is allowed differs by each software’s terms (EULA). Be sure to check the license terms before adopting.

Internal server/MacInternal PCs

Entirely inside your internal network, with no external cloud

SetupThe server (bus) is installed directly on a company Mac or server. Nodes on the same internal network find the server automatically (oah.local) or connect to an address you specify.
EffectInstructions and results travel only between the server and nodes inside the company. No separate cloud account or external relay service is needed.

If you use Claude as the AI brain, instructions are sent to Claude while it makes decisions. To keep that part internal too, see the air-gapped setup below.
