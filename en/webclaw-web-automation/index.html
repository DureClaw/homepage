Short FAQ

Three things to know

How do logins work?

macOS starts with a dedicated profile, separate from your Chrome. Sign in once to the sites you need. Windows can import your existing Chrome profile; if Chrome 137+ App-Bound Encryption prevents the session from carrying over, sign in once in the new browser.

Can I keep using my own Chrome?

Yes. You can still load the webclaw extension bundled with the DureClaw Server app into Chrome, Edge, or Whale. Server app setup →

Why does a signing warning appear?

This build is unsigned. On macOS choose right-click → Open; on Windows choose More info → Run anyway in SmartScreen.
