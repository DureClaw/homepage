Install the extension by itself (advanced)

Skip the app-prepared folder and fill in the config yourself. This also works when connecting to a server on another machine.

webclaw extension zip Chrome MV3 · about 85 KB · v0.11.5↓
  1. Unzip and find the inner webclaw-extension folder.
  2. Copy config.local.json.example to config.local.json and fill in the values below.
  3. chrome://extensions → Developer mode → Load unpacked → select the webclaw-extension folder.
{ "bus": "100.x.x.x:4000", "secret": "server secret", "workKey": "WK-...", "name": "webclaw@my-browser", "role": "executor", "caps": ["browser", "fetch", "dom", "agent", "webclaw"] }

Get the server address from Copy node connection address in the app, the secret from server.secret, and the Work Key from the control panel. Never share a file containing the secret.

FAQ

Before you install

Isn't webclaw on the Chrome Web Store?

webclaw currently ships inside the server app and is loaded as an unpacked extension. That keeps you on the latest build without waiting for store review. It works in Chrome, Edge, Whale, and other Chromium browsers.

Do I need Bun or Node on Windows?

No. The server installer includes dureclaw-mcp.exe, so it installs and registers without Bun or Node. The separate MCP zip is an advanced path for updating MCP without the installer.

Does an Intel Mac work?

The server app dmg is for Apple Silicon (M1–M4). On Intel Macs, use the terminal install (bash <(curl -fsSL https://dureclaw.baryon.ai/install)) and the one-line MCP install (bash <(curl -fsSL https://dureclaw.baryon.ai/mcp), requires Bun).

Can I use just the Claude Code plugin without MCP?

Yes. The DureClaw Claude Code plugin handles local work and multi-machine orchestration. To connect other agents (Cursor, Codex, Orca Mobile, and so on) to the browser, use the MCP server the installer registers automatically.

Can one instruction drive Chrome on several computers?

Connect webclaw on each computer and you'll see nodes like webclaw@PC-A and webclaw@PC-B. Send tasks to each and they run in parallel. The free personal edition covers up to two machines including the server.

How are secrets and tokens handled?

The server-issued secret stays in the server app's data folder, and the MCP setup wizard reads it automatically. It is never printed to the screen. The generated mcp.json contains the secret, so don't share it.
