DureClaw Browser 2nd gen NEW
2026-11-11
  • featStandalone browser — Chromium + webclaw + MCP — One installer bundles Chromium, the webclaw extension, and MCP without Chrome Web Store review. macOS uses a dedicated profile (one-time sign-in); Windows can import existing Chrome cookies and logins
  • featAuto-registered for every MCP agent — Claude Code, Claude Desktop, Cursor, Codex, OpenCode, Gemini, VS Code, Windsurf, and Orca Mobile get a dureclaw MCP entry. No run, tab, or site limits
  • testVerified on real Windows 11 LTSC — silent install, installed-file checks, headless Chromium + webclaw extension load, and Chrome profile import all pass. macOS Apple Silicon verified with a bus connection and MCP screenshot
  • featDownload — macOS .dmg · Windows .exe · Setup guide
v0.5.5 latest
2026-11-02
  • fixTray icon not appearing after Windows node install — The tray script is now saved as UTF-8 with BOM, fixing a problem where Windows PowerShell 5.1 garbled Korean text and stopped running. Installing with DureClaw-Agent-Setup now shows the tray immediately, and it starts automatically at every login
  • fixRe-register when the server refuses — If the server is reinstalled or a token is revoked and the connection is refused, the node no longer stops; it requests registration again. The tray shows a connection status dot and notifications (Windows)
  • featTray connection info and connection test — Clicking the status line shows status, node, server, auth, version, private network, and config/log paths in one window. Added a "Test connection" button and an access token field to the settings window, and "Request registration again" and "Open log folder" to the menu (Windows)
  • fixCommand approval policy — Fixed ordinary commands containing && or | all getting stuck waiting for approval. Shell metacharacters are now blocked only when they bypass an allow pattern; block and approval patterns still apply as before
  • featVersion in the installer file name — Downloads now carry the version, e.g. DureClaw-Agent-Setup-0.5.5.exe, and the download button shows the version
v0.5.4
2026-10-27
  • fixMore reliable private network (Headscale/Tailscale) detection — Fixed the server app hanging when it checked status while the Tailscale GUI was closed, because the status query process relaunched as the app. It now reads the private network address (100.64/10) directly from the interface, so connection status and peer count display correctly with Headscale and ngrok setups too (Mac & Windows)
  • fixTray status refresh — The latest private network status is re-checked every time the menu opens. It no longer gets stuck on "Off" when background throttling (App Nap) delays the periodic check (Mac)
v0.5.3
2026-10-27
  • securityEnterprise task isolation and pure-AI node mode — Setting shell: "off" in ~/.oah/policy.json creates a dedicated node that refuses all shell execution and performs AI work only; workdir_only: true blocks writes outside the working directory and escapes to parent paths (../) at the source
  • securityProtection for sensitive system credentials & mandatory approval for shell metacharacters — Blocks access to sensitive paths such as .ssh, .aws, .env, and the keychain; commands containing shell-chaining metacharacters like ;, &&, |, $() must wait for admin approval
  • securityRespects local Claude Code permission settings on worker machines — The --dangerously-skip-permissions flag is no longer passed by default when running the backend, so local confirmation settings for risky commands stay in effect
  • securityMinimal network binding and stronger authentication — The server binds by default only to the private network IP (Headscale/Tailscale) instead of the public LAN (0.0.0.0), and a vulnerability that escalated to master privileges when the server secret was missing is closed
  • securityNo more master secret hand-off & approval-based keyless nodes — The master secret is no longer printed at the end of installation; worker nodes request access without a key and, once approved, connect with their own unique token
  • featureVersion pinning and auto-update control for company machines — DURECLAW_AUTO_UPDATE=0 prevents unplanned updates, DURECLAW_VERSION pins a specific release tag, and MCP is linked to release tags
v0.5.2
2026-10-26
  • featureOption for your own Headscale private network (VPN) — Choose between the official Tailscale SaaS and the open-source Headscale control server. Run a fully self-hosted network with no external accounts or cloud services
  • featureInteractive network selection menu & CLI flags for the server — Running setup-server.sh offers an interactive three-way choice (Tailscale, Headscale, or LAN only), with --headscale / --tailscale / --no-vpn options
  • featureEasy worker node joining — setup-agent.sh accepts a Headscale join code (JOIN=dcj1:...) interactively, and Windows setup-agent.ps1 gains a -Join parameter
  • featureoah mesh unified CLI — Check private network status (status), control the control server (start/stop), issue join codes (join-code), list nodes (nodes), and switch profiles easily (switch)
  • featureBetter private network status in the Mac & Windows GUI tray — Distinguishes official Tailscale from a self-hosted Headscale network in real time, in the tray menu and notifications
