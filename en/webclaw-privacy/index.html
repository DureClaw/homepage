webclaw Privacy Policy

How the webclaw — DureClaw browser node Chrome extension accesses and processes data.

Effective: 2026-11-10 · Contact: hello@baryon.ai

1. One-line summary

webclaw performs the web tasks you ask for inside your browser. Page content goes only to your local DureClaw server (default 127.0.0.1:4000) and the AI agent you choose. It is not collected or sent to Baryon Labs servers.

2. Data we access

  • Page content — DOM, text, and screenshots of the tab you target, only while a task runs.
  • Tab information — title, URL, and tab group, used to find and group task tabs.
  • Actions — form input, clicks, and downloads you request. Input values are not written to logs.
  • Local configuration — server address, Work Key, server secret, and node name, stored only in chrome.storage.local.
  • Task history — recent task and chat history in the side panel, which you can clear.

3. How we use it

Only to perform the browser automation you requested. We do not use it for advertising, profiling, data sales, or credit decisions.

4. Where data goes

  • Your local DureClaw server — on your computer or a private network you configure (Tailscale/Headscale).
  • The AI agent you choose — Claude Code, Claude Desktop, Cursor, Codex, OpenCode, etc. Their own policies apply to their processing.
  • Baryon Labs servers — no data is sent. The extension contains no analytics or advertising SDK.

5. Retention and deletion

Settings and task history live in your Chrome profile. Removing the extension or clearing chrome.storage.local deletes them. Server task history can be deleted from the server data folder.

6. Permissions and why

  • tabs, tabGroups — find target tabs and group task tabs.
  • scripting, <all_urls> — read, click, and type on arbitrary sites you choose.
  • debugger — Chrome DevTools Protocol for reliable clicks and screenshots on background tabs.
  • downloads — save files and screenshots you request.
  • sidePanel — the per-tab task chat UI.
  • storage — local settings and task history.
  • offscreen — keep the DureClaw bus connection alive under MV3.

7. Security

The server secret is stored in chrome.storage.local and never displayed. webclaw honors your blocked-site and approval policies, and can require approval for irreversible actions such as payments, deletions, or submissions.

8. Children

This extension is not directed to children under 14.

9. Changes

We post changes on this page with a new effective date and mention material changes in extension release notes.
