FAQ

Frequently asked questions

What counts toward “free for 2 machines, including the server”?
The number of computer (machine) identifiers live on the DureClaw bus at the same time. One computer running the main server plus one working computer (2 in total) are free forever. Running several browsers (webclaw), desktops (deskclaw), or agent daemons on the same computer still counts as one machine.
Is it free if I use it alone for work, as long as it is 2 machines or fewer?
Yes. One person linking 2 or fewer PCs for their own productivity is completely free, even for commercial use. The Enterprise plan is required when you connect 3 or more machines or when multiple users share one bus.
When will roadmap features be available?
Roadmap (P1, P2) features are prioritized during Enterprise adoption discussions, with development and validation builds delivered on your required schedule. If you need a review against your internal security policy, please contact us separately.
Can it run on a fully air-gapped network with no internet access?
Yes. DureClaw Enterprise includes its own Headscale network and on-premises server, so it runs as a 100% local encrypted P2P network even on an internal network fully cut off from the internet.
