What is DureClaw?

Unite multiple computers into a cohesive team.
Divided into three simple roles.

the brain

🧠 The Brain

Claude Code running on your primary Mac or workstation. Reasons through complex tasks and plans execution across nodes.

the hands

🤲 The Hands

Lightweight edge agents installed on each machine. Execute assigned tasks locally and stream results back.

the bus

🚌 The Bus

The server application running on your primary host. Bridges the brain and execution hands in real time.

Autonomous Execution Nodes

Why Not Traditional SSH?

Stop logging in manually.
Start delegating across your fleet.

While SSH requires establishing fragile inbound remote shells, DureClaw dispatches tasks asynchronously across heterogeneous machines via an outbound agentic bus.

  • Zero Open Inbound PortsWorker nodes initiate outbound WebSocket connections — zero port forwarding, DMZs, or static public IPs required.
  • Uniform Multi-OS AbstractionDispatch uniform commands and receive structured JSON results across Windows, Linux, macOS, and micro-embedded devices without OS friction.
  • Parallel Fleet ExecutionDistribute concurrent jobs across dozens of machines simultaneously from a single master prompt.

Enterprise-Grade Security

Secret Keys Stay Safe
in a Single Vault

Never distribute production API keys or credentials to worker nodes. DureClaw issues revocable, least-privilege tokens per device.

  • Per-Device Admission TokensWhen a node requests to join, an isolated token is provisioned. Revoke individual access instantly without rotating cluster-wide secrets.
  • Automated Tailnet AdmissionNodes on your private mesh network (Tailscale or Headscale) authenticate zero-touch; unexpected external connections require explicit operator approval. Tailscale Headscale
  • Single-Directional DispatchEdge worker nodes only execute assigned work and report telemetry back. They cannot orchestrate other nodes, preventing lateral privilege escalation.
